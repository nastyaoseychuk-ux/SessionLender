# SessionLender — аватар і редагування кімнати

Додано вибір зображення до 2 МБ при створенні та редагуванні кімнати. Аватар показується у списку кімнат та в шапці. За відсутності фото залишаються ініціали. Редагування назви, опису й аватара доступне лише власнику через кнопку під «Видалити кімнату». Дописи сортуються за датою та ID від нових до старих.

## Застосування

Розпакуйте архів. Із папки архіву запустіть:

```powershell
python .\apply_changes.py "F:\Data\ProjectDock\1\projects\SessionLender\server"
```

Вкажіть фактичну папку сервера з manage.py (також можна вказати корінь проєкту, якщо сервер лежить у server/).

Скрипт спочатку перевіряє всі фрагменти, потім вносить тільки локальні правки. Попередні версії змінених файлів зберігаються в room-avatar-backup-ДАТА-ЧАС/. Якщо код відрізняється настільки, що правку неможливо застосувати однозначно, скрипт зупиниться без зміни файлів. Повторний запуск не дублює правки.

Після застосування перенесіть змінений код на сервер і запустіть міграції:

```powershell
python manage.py migrate
```

Якщо деплой уже використовує RUN_MIGRATIONS=1, достатньо звичайного деплою. Нова міграція messenger/0008_room_avatar.py продовжує наявний ланцюжок 0007_desktop_ticket. Наявні кімнати та дописи зберігаються.

Android та Windows перезбирати не потрібно.

Перевірено завантаження валідного аватара, відхилення невалідного зображення, заборону редагування для учасника й стороннього користувача, збереження власником, збереження попереднього аватара при редагуванні без нового файлу, порядок дописів. Перевірено повторне застосування патча. Візуальна перевірка на вашому сайті не виконувалася.
