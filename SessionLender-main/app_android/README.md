# SessionLender — Android

Java-додаток із системним WebView для сайту SessionLender та foreground WebSocket-сервісом сповіщень. Підтримує авторизацію, чати, завантаження зображень і відкриття подій зі сповіщення. Використовує звичайний SL-логотип.

Сервер за замовчуванням: https://sessionlender.vercel.app. Додаток позначає запити `SessionLenderAndroid/<version>` у User-Agent, щоб сайт приховував кнопку завантаження програми всередині клієнта.

## Зібрати APK (PowerShell)

Потрібні JDK 17, Android SDK 35 і прийняті SDK-ліцензії. Android Studio не обов’язкова.

```powershell
.\build.ps1
```

Інший сервер:

```powershell
.\build.ps1 -ServerUrl "https://your-project.vercel.app"
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

```powershell
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
```

Для оновлення поверх чинного APK потрібен той самий ключ підпису. Поточна версія: 0.3.6, versionCode 7. Для появи User-Agent маркера у встановленій програмі потрібна нова збірка; старі стандартні Android WebView також розпізнаються за wv.

Повні вимоги, методи та порядок збірки: [Say_README_ANDROID_1.0.2.md](../Say_README_ANDROID_1.0.2.md).

Сповіщення працюють через видимий foreground-сервіс, не FCM. Після force-stop або завершення процесу ОС доставка не гарантована. APK у вихідний комплект не включено.

## Оновлення 0.3.5

- Дозвіл RECORD_AUDIO запитується під час першого натискання запису голосового.
- WebView дозволяє лише мікрофон і лише поточному серверу. Камера та сторонні сторінки не отримують доступу.
- Звук повідомлень вбудовано в res/raw/notification.mp3; службове сповіщення з’єднання залишається тихим.
- Новий канал events_sound_v1 застосовує звук після оновлення. Системні налаштування звуку та режим «Не турбувати» зберігають пріоритет.

Перевірка на телефоні: дозволити мікрофон, записати й надіслати голосове; відхилити дозвіл і повторити після його ввімкнення у налаштуваннях; отримати реальне сповіщення у фоні та перевірити звук.

## 0.3.6

Додано MODIFY_AUDIO_SETTINGS для аудіозахоплення WebView. Нормалізовано HTTPS-порт при перевірці джерела запиту мікрофона. Доступ до мікрофона залишається обмеженим сервером додатка.
Поворот екрана змінює розмір існуючого WebView без завантаження головної. При іншому перестворенні Activity відновлюється історія WebView або остання адреса.
