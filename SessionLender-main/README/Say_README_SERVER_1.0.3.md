# Виправленний баг перемішування чату

Сторінка не завантажує ввесь чат зараз, тепер тільки каскадами, додано метод перегляду історії чату з подальших завантажень каскаду повідомлень

# Відображення чату

Змінено відображення DOM в сторінці чату, прибраний скрол і зафіксовано розмір щоб чат не ховався за клавіатуру в телефонній версії

# Виправлено створення кімнати 

При створенні кімнати з по прямій кнопці під користувачем тепер автоматично запрошується відповідний користувач до кімнати

# Додано підтвердження запрошення до кімнати

Тепер при запрошенні до кімнати створенно вікна підтвердження, відразу тепер учасник не додається без підтвердження, підтвердити можна в вкладці кімнати чи в сповіщеннях

# Сторінка презентації

Створений приклад сторінки презентації, додана карусель скриншотів проекту, на сторінці можна змінити тему темної\світлої, скриншоти каруселі відповідають темі сторінки. Сторінка двомовна, англійська та українська
